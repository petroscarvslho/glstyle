# GL Style

Agenda, cobrança e controle financeiro da barbearia GL Style.

- `index.html` (site): página do cliente para pedir horário, sem cadastro.
- `painel.html` (site): painel do dono: agenda, clientes, cobranças por Pix/WhatsApp, caixa, materiais e lucro por pacote.

Desenvolvimento: `npm test` (testes) · `node build.mjs` (gera `dist/`). Branch `gh-pages` = site publicado.
